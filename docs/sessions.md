# Prompt and scripts

Does $t^2-1$ divide $t^3-t$? Open the prompt with `./atlas` in the project directory. Declare an indeterminate, form the principal ideal, and ask whether the second polynomial belongs to it.

```text
atlas> t = coordinates("t")
atlas> I = ideal(t^2 - 1)
atlas> membership(t^3 - t, I).value
True
atlas> membership(t, I).value
False
```

An assignment keeps its result under a name. An expression on a line by itself displays its value. Use `^` for powers, `*` for multiplication and `1/2` for an exact rational coefficient. Tab completes names and fields. A blank line finishes an indented block. If a command fails or you interrupt a block, its assignments and active-ring selection are rolled back. Type `quit` to leave the session.

## Run or save a calculation

Suppose you want to send the divisibility calculation to a colleague. Put the following lines in a file called `divides.atlas`.

```atlas
t = coordinates("t")
I = ideal(t^2 - 1)
print(membership(t^3 - t, I).value)
```

From the shell, `./atlas run divides.atlas` prints `True`. The prompt and scripts accept the same expressions. Use `print` to choose what a script displays, or `print_json(count=len(I.generators))` to write a named result as JSON.

You can also save a calculation you've already made. At the prompt, enter the `print` statement above, then `:save "my session.atlas"`. This writes the successful statements in order, including your explicit prints. Running `./atlas run "my session.atlas"` reproduces the calculation. Saving again to the same path replaces the file. Use `./atlas run -` to read from standard input.

## Inspect a saved value

There are two kinds of help you might want while working. Type `help membership` to look up the function's arguments and an example. Type `help I` to ask about the particular ideal you saved. Try the latter with a polynomial.

```text
atlas> R = ring("x", "y")
atlas> f = y^2 - x^3
atlas> f.parent
QQ[x, y]
```

Now type `help f`. The first line names `R` as the parent of `f`, and the examples use the name `f` so you can try them directly. You can also ask for `help f.parent` or use `:workspace` to see the names grouped under each ring. For the arguments to a method such as `K.element(f)` or `C.pullback(f)`, see [Methods on saved values](value-methods.md).

## Choose the ring of a polynomial

`R = ring("x", "y")` names $\mathbb Q[x,y]$ and gives you its generators as `x` and `y`. Often you can simply write a formula. If the formula arrives as a string, tell Atlas which ring to read it in.

```text
atlas> R = ring("x", "y")
atlas> f = y^2 - x^3
atlas> f == polynomial("y^2 - x^3", ring=R)
True
atlas> x.parent == R
True
```

`R.coordinates` gives the generators in their declared order. The coefficient field defaults to `QQ`. Repeating an ordinary declaration with the same names in the same order returns the same ring in this session. An ideal remembers that ring as `I.parent`. Its `I.ring` field describes the presentation and monomial order for serialization.

### Name a quotient and its coordinates

On the cusp $y^2=x^3$, the two monomials represent the same function. Construct its coordinate ring and give the residue classes names of their own.

```text
atlas> R = ring("x", "y")
atlas> I = ideal(y^2 - x^3)
atlas> K = quotient_ring(I)
atlas> u, v = K.coordinates
atlas> y^2 == x^3
False
atlas> v^2 == u^3
True
atlas> u.parent == K
True
```

`K(x)` is the class of the ambient generator `x`. You can also read a formula directly in the quotient with `polynomial("x", ring=K)`. The names in a string are those in `K.variables`, here `x` and `y`. Retrieve the original generators with `K.ambient.coordinates`. Even an empty coordinate tuple remembers its parent.

`I.quotient_ring` gives the same quotient as `quotient_ring(I)`. Its `defining_ideal` is `I`, and `K.relations` gives a reduced basis of the defining ideal. Use `quotient_ring(I, fresh=True)` if you need an independent copy.

### Create an ideal in a quotient ring

In the cusp ring above, consider the ideal generated by the classes of $y$ and $x^3$. The second generator is redundant because it equals $y^2$ in the quotient.

```text
atlas> J = ideal(v, u^3)
atlas> J.parent == K
True
atlas> membership(K(x^3), ideal(v)).value
True
atlas> membership(u, J).value
False
```

You can get the same ideal from ambient generators with `ideal(y, x^3, ring=K)`. Specify `ring=K` when mixing an ambient generator with a residue class. Use `ideal(ring=K)` for the zero ideal. Sums, products, powers, Gröbner bases, normal forms and membership take the quotient relations into account. For an equality test using both containments, see [Comparing ideals before and after quotienting](../examples/quotient-algebras.md#compare-ideals-before-and-after-quotienting).

To pass to $K/J$, set `L = J.quotient_ring`. Its projection sends elements of `K` to their classes in `L`, so `L.projection(v) == 0` is true. Its representatives still lie in the original polynomial ring `L.ambient`.

### Reuse and rebind coordinate names

Suppose you have a polynomial in $\mathbb Q[x,y]$ and want to introduce another ring, $\mathbb Q[x,z]$. Use different workspace names for the second pair of generators.

```text
atlas> R = ring("x", "y")
atlas> f = x + y
atlas> x2, z2 = coordinates("x", "z")
atlas> x2.parent
QQ[x, z]
atlas> x.parent == f.parent
True
```

A direct declaration `S = ring("x", "z")` here would overwrite the saved `x`. Atlas reports the conflict and preserves the bindings. To work with an *independent copy of the same ring*, ask for one explicitly.

```text
atlas> a, b = coordinates("x", "y", fresh=True)
atlas> a.parent == f.parent
False
```

The generators in both copies are spelled `x` and `y`. Each polynomial still remembers which copy it belongs to. To deliberately rebind the names `x` and `y` themselves, use `T = ring("x", "y", fresh=True)`. To restore the originals, assign `x, y = R.coordinates`. Use a [ring map](#move-a-polynomial-between-rings) to transport a polynomial.

### Name, select and delete rings

When you declare coordinates without naming the ring, Atlas gives it the first free name among `R1`, `R2` and so on. In a **fresh session**, try the following.

```text
atlas> x, y = coordinates("x", "y")
atlas> a, b = coordinates("x", "y", fresh=True)
atlas> ring_name(x.parent), ring_name(a.parent)
('R1', 'R2')
atlas> P = a.parent
atlas> ring_name(a.parent)
P
```

Giving the second ring a name frees `R2` for another ring. Type `:workspace` to see each ring with its coordinates, polynomials and ideals. Maps appear with both their domain and codomain. If a ring has several user-assigned names, `ring_name` returns one of them.

Use `use_ring` when a string or a scalar leaves the choice of ring open.

```text
atlas> use_ring(R1)
QQ[x, y]
atlas> polynomial("x+y").parent == R1
True
atlas> ideal(1).parent == R1
True
atlas> ideal(a).parent == P
True
```

An input such as `a` already supplies its own parent. A quotient may also be active. Use `active_ring()` to inspect the selection and `use_ring(None)` to clear it.

`delete_ring(P)` removes the ring and every saved name that depends on it. This includes its quotients, their elements and maps with the deleted ring as an endpoint. For example, an ideal returned by `eliminate` depends on the original ring through its inclusion map. Deleting that ring also deletes the saved elimination result. The returned `.names` lists the affected bindings, and `.was_active` tells you whether the active selection was cleared. An independent ring such as `R1` in this example keeps its values.

## Add, multiply, and raise ideals to powers

For two ideals in the same ring, `I + J` collects their generators and `I * J` takes all pairwise products. Ask for a reduced Gröbner basis to simplify either generating set.

```atlas
x, y = coordinates("x", "y")
I = ideal(x^2, y)
J = ideal(x, y^2)
print(groebner(I + J).generators)  # (x, y)
print(groebner(I * J).generators)  # (x^3, y^3, x*y)
```

The operators `+`, `*` and `^` and the functions `ideal_sum`, `ideal_product` and `ideal_power` work in both scripts and the prompt. To add the principal ideal generated by `f`, write `I + ideal(f)`. The result uses the left ideal's monomial order. [Read the ideal arithmetic script](../examples/ideal-arithmetic.atlas)

## Move a polynomial between rings

How do we add a third variable to a polynomial in $\mathbb Q[x,y]$? Specify where the two old generators go in the larger ring.

```text
atlas> x, y = coordinates("x", "y")
atlas> f = y^2 + x^3
atlas> X, Y, z = coordinates("x", "y", "z")
atlas> include = hom(f.parent, z.parent, images=(X, Y))
atlas> g = include(f) + z
atlas> g.parent
QQ[x, y, z]
atlas> g == Y^2 + X^3 + z
True
```

The first image is substituted for the first generator of the domain, the second for the second. Both substitutions happen simultaneously. Inspect `include.domain`, `include.codomain` and `include.images` to recover the map. Two common maps come with their constructions. A quotient `K` has its projection `K.projection`, and an elimination ideal `E` has an inclusion `E.inclusion` from the surviving coordinates back into the original ring.
