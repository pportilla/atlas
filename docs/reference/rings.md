# Coordinates, polynomials and ring maps

A ring owns its ordered coordinates, and every polynomial remembers the ring it belongs to. These functions declare polynomial and quotient rings over $\mathbb Q$, name and select them in the workspace, read and factor polynomials, and define maps between rings.
