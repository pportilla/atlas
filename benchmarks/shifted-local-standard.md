# Shifted local standard bases and weak normal forms

The benchmark starts both programs from the source equations, rational point, requested monomial order and query. Atlas returns a standard basis or a unit and remainder in the original variables. Singular performs the local standard-basis calculation in centered variables and maps the output back. For normal forms it uses `division(F,G)`, which provides the unit and remainder, and scales both so the unit evaluates to one at the point. Three same-input Singular procedures are timed. The second first computes a global standard basis in the source coordinates and reduces the query against it. This can eliminate a costly high power before shifting, especially when a generator fixes a coordinate. The third procedure factors each generator, keeps the factors that vanish at the point with their multiplicities, and performs the usual local solve. The discarded factors are units in the local ring.

## Certifying the output

The timed programs may return different valid polynomials. A separate Singular process checks the algebraic conditions after timing.

- For a basis, the verifier checks both containments between the input ideal and the output ideal in the local ring. It also checks both containments between the initial monomial ideal of the input and the ideal generated by the heads of the actual output rows. Recomputing a standard basis of the output before taking those heads could conceal a missing basis element.
- For a remainder `r` and multiplier `u`, it checks `u(p)=1`, local membership of `u*f-r`, agreement between `r=0` and local membership of the query, and irreducibility of the leading monomial of a nonzero remainder. When Atlas reports a standard remainder, the verifier additionally checks that every term lies outside the initial ideal. A weak remainder may retain a reducible tail.
- Small examples use literal rational translation. Each actual output head is extracted independently from the source-coordinate polynomial by binomial Taylor coefficients, using degree then the specified tie order. The checks use local `ds` for membership, which is independent of monomial order. The reference heads use `Ds` or `ds` according to the requested order. For homogeneous chart models, they use global `Dp` or `dp` because all terms of each homogeneous polynomial have one degree. On this Singular 4.4.1 installation, for example, in a three-variable `Ds` ring the first generator of `((x+y)^2,(x+z)^2,(y+z)^2)` leaves `-z^2` under reduction by Singular's own `std(I)`. The membership check in `ds` catches this behavior.
- For the large structured cases, write `h=x-p` on each moving axis where a power `x^N` occurs. When all terms involved are powers of `x^N`, the verifier can use the coordinate `x^N-p^N` because its derivative `N*p^(N-1)` is nonzero. The associated graded coordinate change is diagonal and preserves the prescribed initial monomials. The primitive oblique axis union uses a different coordinate change with invertible, nondiagonal Jacobian. Its homogeneous tangent ideal in the actual directions is obtained by substituting the three full linear parts into the ideal of the three axes. The reported generators are tested against these transformed heads, preserving the original monomial order. For the high-degree oblique basis the verifier first proves mutual ideal membership in a larger polynomial ring with a free variable for `x^N*y^N`. Substituting the actual monomial yields the two source-ideal inclusions. Otherwise the verifier replaces each `x^N` by its degree-four Taylor polynomial in `h` plus `h^4*s` in an auxiliary local ring with a new variable `s`. The true divided difference `(x^N-Taylor_4)/h^4` vanishes at the point. Substituting this polynomial for `s` carries every verified membership into the original local ring and preserves local units. A congruence established in the auxiliary ring therefore certifies the exact original, regardless of the exponent size. For the three parameter squares, the fourth power of the maximal ideal vanishes because the three independent linear forms are coordinates in the chart. Singular verifies this inclusion. This also allows the certificate to be checked exactly in the quotient by the fourth power, keeping all Taylor coefficients of degrees zero through three. For the coordinate slice the generator `x-1` kills the additional term in `y*z+(x^N-1)*z^2`.

## Reproduction

Build the native CPU CLI in the repository build environment. On Linux with Singular installed, run the following, choosing an available logical CPU. An optional `--baseline-root` points to a previous Atlas executable and its matching native library.

```sh
make -C native -f groebner.mk build/local_algebra
python3 benchmarks/shifted_local_standard.py --cpu 5 --repeats 3 --seconds 3 --memory-mib 768 --output /tmp/shifted-standard.json
```

Each solve starts a fresh process. The timing includes parsing and printing the actual polynomial outputs. Each timing has the same wall-clock and virtual-memory limit. Verification runs in separate processes with a longer wall-clock limit. The JSON retains every timed sample, certified polynomial outputs, both orders where exercised, full inputs and binary hashes. The final survey resumed after its verifier was updated to handle the sparse oblique output. All prior polynomial outputs were reverified and their original solver timings retained on the same frozen binaries. Failed runs have no inferred elapsed time. The shared host remains available to other jobs.
